    * **Where it's used:**
        * The exponent **"x"** in the logo (giving it the "scribbled math" look).
        * The main page header for **"Stories"**.
        * The titles inside the **Story Cards**.

3.  **Patrick Hand** (`marker-font`)
    * **Style:** A neat, thinner handwriting font, resembling notes taken with a pen.
    * **Where it's used:**
        * Section subtitles (e.g., "Analysis, notes, and insights...").
        * Category tags (e.g., "Calculus", "Politics").
        * The "STk" search badge.

4.  **Inter** (`font-sans`)
    * **Style:** A clean, modern sans-serif font.
    * **Where it's used:**
        * General body text (descriptions, dates).
        * Navigation links.
        * Buttons (e.g., "Read Story").

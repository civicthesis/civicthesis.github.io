## Domain, Codomain, and Range

<CinematicCard theme="noir" title="Key Definitions">
  <ul>
    <li><strong>Domain (A):</strong> The set of all possible inputs.</li>
    <li><strong>Codomain (B):</strong> The set of all potential outputs.</li>
    <li><strong>Range:</strong> The set of actual outputs produced by the function.</li>
  </ul>
</CinematicCard>

## Types of Functions

<div class="grid grid-cols-1 md:grid-cols-2 gap-6 my-8">
    <HandDrawnBox title="One-to-One (Injective)" variant="tip">
        Every element in the domain maps to a **unique** element in the codomain.
        
        *Distinct inputs have distinct outputs.*
    </HandDrawnBox>
    
    <HandDrawnBox title="Onto (Surjective)" variant="warning">
        Every element in the codomain is mapped to by **at least one** element in the domain.
        
        *Range = Codomain.*
    </HandDrawnBox>
</div>

<CinematicCard theme="paper" title="Bijective Function">
  <p>If a function is both <strong>One-to-One</strong> and <strong>Onto</strong>, it is called a Bijective function.</p>
  <p class="mt-2">Bijective functions are invertible!</p>
</CinematicCard>

## Inverse Functions

If $f: A \to B$ is a bijection, then there exists an inverse function $f^{-1}: B \to A$ such that:

$$f^{-1}(f(x)) = x$$

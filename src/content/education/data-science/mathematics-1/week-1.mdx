# Sets and Relations

## What is a Set?

A set is a well-defined collection of distinct objects.

<HandDrawnBox title="Definition" variant="note">
  **A set is a collection of well-defined objects.**
  
  Think of it like a bag of unique items where order doesn't matter.
</HandDrawnBox>

### Examples

<HandDrawnBox title="Common Sets" variant="tip">
  *   The set of all vowels in English alphabet: $V = \{a, e, i, o, u\}$
  *   The set of natural numbers: $\mathbb{N} = \{1, 2, 3, ...\}$
</HandDrawnBox>

## Operations on Sets

1.  **Union ($A \cup B$):** Elements in A or B or both.
2.  **Intersection ($A \cap B$):** Elements in both A and B.
3.  **Difference ($A - B$):** Elements in A but not in B.

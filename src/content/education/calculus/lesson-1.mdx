A limit tells us the value that a function approaches as the input approaches some value.

<VideoEmbed id="riXcZT2ICjA" title="Introduction to Limits" />

### Key Concepts
- **Left-hand limit:** The value approached from the left.
- **Right-hand limit:** The value approached from the right.
- **Existence:** A limit exists if and only if the left-hand and right-hand limits are equal.

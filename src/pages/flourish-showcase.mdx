# Data Storytelling with Flourish-Style Charts

Data visualization is not just about showing numbers; it's about telling a story. Standard bar and line charts are useful, but sometimes you need more dynamic or comparative tools to highlight changes over time or drastic shifts between two states.

We've implemented a new set of "Flourish-style" components for CivicThesis to help users create compelling data narratives.

## 2. Slope Charts: Analyzing Change

Slope charts are simple yet powerful. By connecting two points, they immediately show:
1.  **Direction:** Did it go up or down?
2.  **Magnitude:** How steep was the change?
3.  **Ranking:** Did the order of categories change?

### Example: Life Expectancy (1960 vs 2020)

This chart compares life expectancy at birth for selected countries, highlighting significant improvements in developing nations compared to steadier growth in developed ones.

<SlopeChart

## 3. Treemap: Hierarchical Data

Treemaps display hierarchical data using nested rectangles. The area of each rectangle corresponds to its value.

export const debtData = {
  name: "Global Debt",
  children: [
    { name: "United States", value: 33400, color: "#3B82F6" },
    { name: "China", value: 14000, color: "#EF4444" },
    { name: "Japan", value: 9200, color: "#10B981" },
    { name: "United Kingdom", value: 3500, color: "#F59E0B" },
    { name: "France", value: 3300, color: "#6366F1" },
    { name: "Italy", value: 3000, color: "#EC4899" },
    { name: "India", value: 2900, color: "#8B5CF6" },
    { name: "Germany", value: 2800, color: "#14B8A6" },
    { name: "Canada", value: 2200, color: "#F97316" },
    { name: "Brazil", value: 1800, color: "#06B6D4" },
  ]
};

<Treemap
  title="Top 10 Countries by National Debt (Billions USD)"
  subtitle="Comparing the scale of national debt across major economies (2024 Est.)"
  data={debtData}
  height={500}
  source="IMF / World Bank"
/>

Using a **Squarified** layout algorithm to ensure rectangles maintain a healthy aspect ratio for readability.

## 4. Sunburst: Radial Hierarchy

Sunburst charts are like treemaps but use a radial layout. They are effective for showing multi-level hierarchy where the "center" is the root.

  title="Global Debt Distribution (Sunburst)"
  subtitle="Radial view of national debt"
  data={debtData}
  height={500}
  source="IMF / World Bank"
